# Chào mừng — Developer Onboarding Guide

Xin chào và chào mừng bạn đến với đội ngũ kỹ thuật! 🎉

Tài liệu này sẽ giúp bạn nhanh chóng làm quen với môi trường làm việc, công cụ và quy trình trong tuần đầu tiên.

## Lịch trình tuần đầu tiên

### Ngày 1-2: Setup & Orientation
- Nhận laptop và thiết lập tài khoản
- Cài đặt môi trường phát triển
- Meeting 1:1 với manager và teammates

### Ngày 3-4: Hiểu hệ thống
- Đọc tài liệu kiến trúc của team
- Shadow một senior engineer trong một ngày làm việc
- Xem code tour của codebase chính

### Ngày 5: First Contribution
- Fix một bug nhỏ hoặc cải thiện documentation
- Submit PR đầu tiên
- Review process

## Checklist onboarding

### Tài khoản cần thiết

- [ ] Email công ty (`ten@example.com`)
- [ ] Okta SSO — nhận invitation từ HR
- [ ] Slack — tham gia các channel liên quan
- [ ] GitHub — được thêm vào org `my-org`
- [ ] Jira — project của team
- [ ] 1Password — password manager
- [ ] Backstage Portal — `https://backstage.example.com`

### Công cụ cần cài

- [ ] Git, GitHub CLI (`gh`)
- [ ] Docker Desktop
- [ ] kubectl + kubeconfig (nhận từ Platform Team)
- [ ] IDE (VSCode hoặc JetBrains theo sở thích)
- [ ] Slack desktop app

### Tài liệu cần đọc

- [ ] [Engineering Principles](culture/principles.md)
- [ ] [Git Workflow](process/git-workflow.md)
- [ ] [Code Review Guidelines](process/code-review.md)
- [ ] Architecture doc của team (hỏi lead của bạn)
