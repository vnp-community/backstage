# Policies Overview

## Cấu trúc chính sách bảo mật

Tổ chức của chúng tôi có 3 cấp độ chính sách:

```
┌───────────────────────────────────────────────────────┐
│                  Security Policies (Cấp 1)            │
│          "Chúng ta làm gì và tại sao"                 │
│   → Access Control, Data Classification, Incident...  │
└───────────────────────────────────────────────────────┘
                         ↓
┌───────────────────────────────────────────────────────┐
│              Security Standards (Cấp 2)               │
│          "Chúng ta làm như thế nào"                   │
│   → Password Standard, Encryption Standard...         │
└───────────────────────────────────────────────────────┘
                         ↓
┌───────────────────────────────────────────────────────┐
│              Security Procedures (Cấp 3)              │
│          "Các bước thực hiện cụ thể"                  │
│   → Vulnerability management process, Onboarding...   │
└───────────────────────────────────────────────────────┘
```

## Quy trình cập nhật chính sách

1. Security Team soạn thảo/cập nhật chính sách
2. Review bởi Legal và Compliance
3. Approve bởi CISO
4. Thông báo toàn tổ chức
5. Training nếu có thay đổi lớn
6. Update tài liệu này

## Exception Process

Nếu cần ngoại lệ với một chính sách:

1. Ghi rõ lý do kinh doanh
2. Đánh giá rủi ro bổ sung
3. Đề xuất biện pháp bù đắp (compensating controls)
4. CISO approve
5. Review hàng quý
